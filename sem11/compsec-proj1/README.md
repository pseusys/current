# CompSec lab 1

> How to run?

1. Download [qemu disc image](https://drive.google.com/file/d/175TjUEESCko1JcbwoPieNLjGx4qgc2Si/view?usp=drive_link) and store it in this directory.
2. Open 2 terminal windows (or tabs).
3. Run `make up` in one of them and wait until `comp4634 login` text appears on screen (no need to login).
4. Run `make xploitN`, where `N` is a number from 1 to 5 in the other.
5. Input `user` password (`comp4634`) when necessary.
6. Enjoy :)
